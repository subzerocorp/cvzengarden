## Why
Every first-party theme leaks each visitor's IP to jsDelivr and loses its face when printing offline; a hosted résumé page must not phone a CDN (Marcus, Mika; BAR-L1).
## Covers
F6 — Marcus, Mika
## Scope in
- Vendor the exact woff2 files the three themes reference (EB Garamond, IBM Plex Sans, Syne, Outfit — all SIL OFL) under `themes/fonts/<family>/` with each family's `OFL.txt`
- `@font-face src` in `themes/*.css` becomes `local("…")`, then `url("fonts/…")` (relative to the CSS file); no `cdn.jsdelivr.net`
- `frontend/scripts/copy-dist.mjs` copies `themes/fonts/` to `dist/themes/fonts/`; `serve.mjs` already serves `.woff2`
- `themes/README.md`: first-party fonts are self-hosted; contributors may `@font-face` any https origin or self-host in their PR (the "allowlist" is "any https origin, self-hosted preferred") — this sentence is the C8 font-allowlist answer
- Probe: request log during a full theme cycle has no third-party host
## Scope out
- Subsetting/optimising fonts beyond the latin files already used
- Font licensing for contributor themes (their responsibility; stated in ZG-18's CONTRIBUTING)
- Changing typefaces
## Acceptance criteria
- [ ] `grep -rn "jsdelivr" themes/*.css` prints nothing; `grep -c "@font-face" themes/quarto.css` is unchanged from before
- [ ] Probe `ZG-13/no-third-party`: cycling all three themes and printing, the Playwright request log contains only `127.0.0.1`/`localhost` URLs
- [ ] Probe `ZG-13/fonts-load`: after selecting Quarto, `document.fonts.check('12px "EB Garamond"')` inside the iframe is `true` and at least one `/themes/fonts/` request returned 200 `font/woff2`
- [ ] Probe `ZG-13/fallback`: with `/themes/fonts/**` requests aborted, `.rz-name` computed `font-family` still resolves and the page has no layout overflow (BAR-U2)
- [ ] `themes/fonts/*/OFL.txt` exists for every vendored family; `themes/README.md` states the self-host rule and the "any https origin" contributor rule
- [ ] BAR-L1 pairwise distinctness probe still passes
- [ ] `just verify` green
