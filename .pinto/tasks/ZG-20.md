## Covers
C7 — Devon, Mika
## Scope in
- `frontend/scripts/lint-theme.mjs` (`npm run lint-theme <file.css>`), Node only, no new dependency: pure `checkTheme(source) -> {errors, warnings}` (each `{code, line, message}`) plus a thin CLI
- Exit-code contract: any error → exit 1; warnings only → exit 0; the CLI prints `<file>:<line> error <code>: <message>` / `warning …` lines and a final `N errors, M warnings`
- Selector rule (`selector`): every complex selector (each comma-separated selector, split on combinators) must contain at least one compound built on `html`, `body`, `.rz-*`, or `[data-rz-*]`; type selectors, the universal selector `*`, pseudo-classes and pseudo-elements are allowed anywhere in a selector that has such a compound; any non-`rz-` class or any `#id` anywhere in the selector is an error; a selector whose compounds are only `*`/type/pseudo is an error. Consequence: `.rz-resume a`, `.rz-summary p`, `.rz-resume a:focus-visible`, `.rz-entry-header > *` (Nightgarden line 274, Switchyard line 121), `html *`, `html *::before` (all three themes) pass; `a`, `li`, `*`, `*::before`, `.rz-resume .btn`, `#root` fail
- Other errors: missing/invalid `/* rz-target: web|print|both */` (`rz-target`); `<script` (`script`); `@import` (`import`); a `content:` string containing a run of 3+ Unicode letters (`\p{L}{3,}`, so `"名前"` fails) with no `counter(`/`counters(` in the same value (`content`); `@media print` block that sets `background` or `background-color` with luminance < 0.5 on `html`/`body`/`.rz-resume` without `color-scheme: light` (`print-ink`)
- Warnings: missing `Author:`/`URL:`/`License:` header (`header`); `url(` to a non-https **absolute** origin (`url-origin`; relative and root-relative URLs are same-origin and never warn — after ZG-13 every first-party `@font-face` uses `url("fonts/…")`); `@keyframes` present without `prefers-reduced-motion` (`motion`); a `content:` letter-run in the same value as `counter(`/`counters(` — e.g. a print footer `content: "Page " counter(page)` (`content-counter`, the human reviewer decides); a print `background`/`background-color` whose value cannot be resolved (`var(--x)`, gradients) (`print-ink-unresolved`, never silence)
- Allowed at-rules: `@page` `@font-face` `@keyframes` `@media` `@supports` `@layer` `@property` `@container`
- `probes.mjs` runs `checkTheme` on every `themes/*.css` except `_blank.css` as the **first** step of `staticProbes()` (before the `Generated Themes.elm is missing <id>` catalog check, which also fails for an uncatalogued file), replacing the by-name first-party checks; it prints `PASS  ZG-20/lint <file> 0 errors` per clean file and one `FAIL  ZG-20/lint <file>:<line> error <code>` line per error (`fail()` records and continues; it never exits early)
- Shared fixture (owner: this PBI) `frontend/fixtures/bad-theme.css`, exactly five lines: `/* rz-target: both */` · `/* Name: Bad Theme */` · `.theme-switcher { display: none; }` · `.rz-name::after { content: "Jordan Hale"; }` · `@media print { body { background: #000; } }` → errors `selector` (line 3), `content` (line 4), `print-ink` (line 5); warnings `header` ×3
- `CONTRIBUTING.md` names the command
## Scope out
- A full CSS parser (regex/tokeniser over declarations is enough; document the known limits in the file header)
- Running in CI (human infra)
- Judging taste, size, or accessibility contrast
