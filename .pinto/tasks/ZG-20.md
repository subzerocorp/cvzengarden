## Why
Devon could not tell whether Cathode's `"$ "` and `counter()` were legal and had no lint to run; one command that prints the same verdict the reviewer applies removes the guesswork (Devon, Mika).
## Covers
C7 — Devon, Mika
## Scope in
- `frontend/scripts/lint-theme.mjs` (`npm run lint-theme <file.css>`), Node only, no new dependency: pure `checkTheme(source) -> {errors, warnings}` plus a thin CLI
- Errors: missing/invalid `/* rz-target: web|print|both */`; `<script`; `@import`; a selector outside `html`, `body`, `.rz-*`, `[data-rz-*]`, `::`/`:` pseudo, `@page`/`@font-face`/`@keyframes`/`@media`/`@supports`/`@layer`/`@property`/`@container` at-rules; a `content:` string containing a run of 3+ letters (résumé-word proxy; decorative glyphs, punctuation, `counter()`, `attr()` pass); `@media print` block that sets a dark `background` on `html`/`body`/`.rz-resume` (hex/rgb luminance < 0.5) without `color-scheme: light`
- Warnings: missing `Author:`/`URL:`/`License:` header; `url(` to a non-https origin; no `prefers-reduced-motion` while `@keyframes` present
- `probes.mjs` runs `checkTheme` on every `themes/*.css` except `_blank.css` (replaces the by-name first-party checks); exit code 1 on any error
- `CONTRIBUTING.md` names the command
## Scope out
- A full CSS parser (regex/tokeniser over declarations is enough; document the known limits)
- Running in CI (human infra)
- Judging taste, size, or accessibility contrast
## Acceptance criteria
- [ ] `npm run lint-theme themes/quarto.css`, `nightgarden.css`, `switchyard.css` exit 0 with `0 errors`
- [ ] Unit tests (`node --test frontend/scripts/lint-theme.test.mjs`): `.theme-switcher{}` → error `selector`; `<script` → error `script`; `.rz-name::after{content:"Jordan Hale"}` → error `content`; `content:"$ "`, `content:"▌"`, `content:counter(rz-sec)` → no error; missing `rz-target` → error; `@media print{body{background:#000}}` → error `print-ink`; `@keyframes` without reduced-motion → warning
- [ ] A fixture `frontend/fixtures/bad-theme.css` combining three errors makes the CLI exit 1 and print each error with a line number
- [ ] `probes.mjs` fails (exit 1) when a temporary `themes/zz-bad.css` copy of the bad fixture is present, and passes after removal
- [ ] `grep -n "lint-theme" CONTRIBUTING.md package.json` hits both
- [ ] `just verify` green
