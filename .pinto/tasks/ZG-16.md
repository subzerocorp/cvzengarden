## Why
For a Zen Garden the byline is the point; today `generate.mjs` throws the `Author:` header away and `_blank.css` has no field for a portfolio link (Mika).
## Covers
C2 — Mika
## Scope in
- `generate.mjs parseTheme` reads `Author:` and `URL:` (portfolio/link) header lines; `Generated/Themes.elm` `Theme` gains `author : String` and `url : Maybe String`
- Theme card shows "by <author>" with the link when present; first-party headers become `Author: ResumeZen` / `URL: https://github.com/subzerocorp/cvzengarden`
- `_blank.css` header gains `URL:` line with guidance; `themes/README.md` documents the header fields (`Name`, `Author`, `URL`, `License`, `rz-target`)
- Missing `Author:` → card shows no byline (never a fake one)
## Scope out
- Designer profiles, avatars, or a store-backed catalog (RZ-6 lineage; not needed for credit)
- Sorting/featuring
## Acceptance criteria
- [x] Probe `ZG-16/byline`: each `#theme-option-*` for the three first-party themes contains `.theme-switcher__author` with text `by ResumeZen` and an `<a href="https://github.com/subzerocorp/cvzengarden" rel="noopener">`
- [x] Unit test for `parseTheme` (node test in `frontend/scripts/`): header with `Author: Mika Tan` and `URL: https://mika.example` yields `{author:"Mika Tan", url:"https://mika.example"}`; header without `Author:` yields `author: ""`; `URL: javascript:alert(1)` is dropped (only `http(s)` kept)
- [x] Probe `ZG-16/no-fake-byline`: a lab theme without `Author:` (temporary file used only by the probe run) produces a card with no `.theme-switcher__author`
- [x] `themes/_blank.css` contains a `URL:` line; `themes/README.md` lists all five header fields
- [x] Byline link is keyboard-focusable and clicking it does not select the theme (`event.stopPropagation` or separate element)
- [x] `just verify` green
