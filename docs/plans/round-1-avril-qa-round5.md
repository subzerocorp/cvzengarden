Two ACs do not survive contact with the sheets:

1. **`bullets-print` cannot be passed by the marker the scope prefers.** The AC's first clause is: `getComputedStyle(el, '::before').content` is not `none` / `normal` / `""` **or** `list-style-type` is not `none`. Its second clause then explicitly admits "an empty-content bar's `::before`" with `width` > 0, `height` > 0, an inked `background-color` and `print-color-adjust: exact`. Those two clauses contradict each other for exactly the implementation scope-in recommends for Switchyard and Nightgarden ("ink-coloured bar … or a text glyph"): a bar has `content: ""`, which the CSSOM serialises as `""`, and every first-party theme sets `.rz-bullets { list-style: none }` (verified in all three), so the `li`'s computed `list-style-type` is `none`. The first clause fails, the probe fails, and the only way to pass is a glyph — which the scope does not require. Two testers reading `""` differently (the two-character serialisation vs. "an empty string") get two verdicts, and a tester who reads it as written fails a correct bar. Required: state the marker-exists clause so that an empty-content bar with non-zero box dimensions satisfies it (e.g. "`content` is a non-empty string, **or** `content` is `""`/`none` and the `::before` box has `width` > 0 and `height` > 0, **or** `list-style-type` is not `none`"), and keep the ink clause as is. One sentence.
2. **`no-forced-break` cannot fail on the theme that has the defect.** The AC says "no first-party theme has `break-inside: avoid` or `avoid-page` on `.rz-section` (static grep over the print blocks via `extractMediaBlocks`)". (`page1-fill` would still catch a forgotten Quarto, so the defect ships nowhere; but an AC that cannot fail is theater and I have rejected the same pattern in ZG-12 `rise-css-structure`.) Required: scan the whole sheet (top-level rules **and** `@media print` blocks), or replace the grep with the browser fact it stands for — in print emulation on the top-level page, `getComputedStyle(section).breakInside` is `auto` for every `.rz-section` in all three themes and `breakBefore` is not `page` on `.rz-section--projects` under Switchyard — and state that the pre-change Quarto sheet fails it (line 176).

Non-blocking (fold in with the fix):

- **Fixture sizing is still marginal at 682 px.** At Quarto's 11 pt print size, 4 entries × 6 highlights × 25 words is roughly 900–1000 px of experience — near the 952 px threshold. The body's "lean long — the AC decides" is the right stance; say explicitly that the fixture's ranges may be exceeded (not merely leaned on) if `fixture-trips-e1` does not hold, so the implementer does not treat the ranges as a ceiling and the AC as unattainable.

**REJECT ZG-11 — `bullets-print`'s marker-exists clause (`content` not `""` or `list-style-type` not `none`) fails by construction on the empty-content ink bar its own second clause admits, because every first-party theme sets `.rz-bullets { list-style: none }` and a bar's `content` serialises to `""`; and `no-forced-break` greps only `extractMediaBlocks` output while Quarto's `.rz-section { break-inside: avoid-page }` is a top-level rule (line 176), so the AC cannot fail on the theme that has E1. ### Fresh review

The rule set is now decidable on every construct the first-party sheets contain (I also checked `@page :first` in Quarto: it is an at-rule, and AC 1 would fail a tokenizer that mistook `:first` for a pseudo-only selector — so that case is covered by a real AC, not by luck), the fixture is five stated lines with three named errors at named line numbers, the exit-code contract has both branches, and the integration AC now names the lint's own output. One unit case contradicts the rule it tests:

- **`content:"名前"` → `content` cannot pass under `\p{L}{3,}`.** Scope defines the `content` error as "a `content:` string containing a run of 3+ Unicode letters (`\p{L}{3,}`, so `"名前"` fails)". `名前` is two code points (U+540D, U+524D), both `\p{L}`; a run of two letters does not match `{3,}`. The stated regex says no error; the unit test AC says `content`. An implementer who follows the scope fails the test; one who lowers the threshold to `{2,}` passes the test and violates the scope (and starts flagging `"vs"`, `"Jr"`, `"at"`). Two testers, two verdicts — the same one-token contradiction I rejected ZG-17 for in cycle 4. Required: pick one — change the example to a three-letter string (`"名前は"`, or `"氏名欄"`), or lower the threshold and say why, or add a script-class clause (e.g. any run of ≥ 2 `\p{Script=Han}`/`\p{Script=Hiragana}`/`\p{Script=Katakana}` counts as a word) with the matching unit cases. The rule and the example must agree.

Non-blocking (fold in with the fix):

- **Meta-test cost and wiring.** `probes.mjs` has no static-only mode: it builds nothing itself but runs `staticProbes()` and then the whole Playwright suite in one process, with `process.exit(1)` at the end. The meta-test therefore runs the full probe suite **twice** (with and without `zz-bad.css`), needs a built `dist/`, and needs `PROBE_PORT` free — and `node --test frontend/scripts/lint-theme.test.mjs` is not part of `just verify` today. Say how the unit tests join `just verify` (a `test-lint` recipe or `npm test` step), that they run **after** `npm run build`, and that the meta-test sets `PROBE_PORT` to a port distinct from the outer run's. Alternatively give `probes.mjs` a `--static` flag that stops after `staticProbes()` and have the meta-test use it — one line, and it makes the meta-test seconds instead of minutes. Either is fine; the AC is satisfiable as written, just slow and easy to mis-wire.
- **Unit case for `@page :first{}`** → no error, so the at-rule handling is pinned in the unit file as well as by AC 1.
- **Unit case for `.rz-name::selection{}` / `.rz-resume ::marker{}`** → no error, since pseudo-elements are explicitly allowed and designers will write them.

**REJECT ZG-20 — the `content` unit case `content:"名前"` → `content` contradicts the stated rule `\p{L}{3,}` (two letters do not make a run of three), so the scope and the AC cannot both be satisfied and two implementers get two verdicts; align the example or the threshold and say which.
