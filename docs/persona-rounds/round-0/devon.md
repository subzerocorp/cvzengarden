## What worked

- The contract is real. I wrote all 380 lines of Cathode from `skeleton/CLASS-CONTRACT.md` §6 + `example.html` without once needing the renderer, and it held up against every fixture I generated (sparse, emoji/RTL, long URLs, certificates, weird dates, 2000-job résumé). The "one tree, restyle don't rearrange" promise is true in the code: `emit.rs` is one path, no per-theme branches.
- Drop-in catalog is the contribution flow, it just isn't told to anyone: copied the repo to my lab, added `themes/cathode.css`, `npm run build` → `Generated 4 theme(s): cathode, nightgarden, quarto, switchyard`; `/?theme=cathode` selected it, badge BOTH, Print filter included it (`/tmp/persona-lab/devon/lab-switcher-cathode.png`). `generate.mjs` reads `Name:` and `rz-target:` straight out of my header comment. If a PR merges, the theme is live. That should be the first sentence of a CONTRIBUTING.
- Renderer speed and escaping: 2000 jobs × 20 bullets, 4.8 MB JSON → 7.6 MB HTML in 286 ms. `<script>` in the name and `"` in the email were escaped in text, `<title>`, and attributes. `{}` and `{"basics":{"name":"Ada"}}` both produce a clean tree with nothing invented.
- The switcher: `?theme=` permalink and Back work (`/?theme=quarto` → Back restored Quarto), dual-link swap in `ports.js` (no unstyled flash), Print preview flips Nightgarden from `rgb(7,11,20)` to `rgb(255,255,255)` in the iframe, and Print calls `iframe.contentWindow.print()` so the theme's own print CSS is what prints. Injecting Cathode into the sandbox and using the chrome's Print preview worked exactly like a first-party theme.
- Nightgarden's print block is a good worked example of the rule I was missing — once I read it (`@media print { html, body, .rz-resume { background:#fff; color-scheme: light } }` plus `animation: none !important`), v2 took twenty minutes.
- The chrome itself is calm, keyboard-reachable, and mobile-stacks sanely (`/tmp/persona-lab/devon/site-mobile.png`).
